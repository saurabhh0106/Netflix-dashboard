## Netflix-dashboard
This project presents an interactive Netflix Content Analysis Dashboard developed using Tableau. The dashboard analyzes Netflix’s global content library to uncover insights about movies and TV shows, including trends by genre, country, release year, and ratings.
The goal of this project is to demonstrate how data visualization can help understand content distribution, audience preferences, and platform trends.

🎯 Business Problem

Streaming platforms like Netflix manage thousands of titles across multiple genres and regions. Understanding the distribution and trends of content is important for making decisions about:

Content acquisition

Regional content strategy

Genre popularity

Release trends

🛠 Tools & Technologies Used :
Tableau – Dashboard development and data visualization

Excel / CSV Dataset – Netflix content dataset

Data Cleaning & Data Preparation
